A landing page to support lead generation: I defined the structure and user journey, wrote the content and built the page in WordPress with Elementor.

## UX focus

Clear layout, intuitive navigation and mobile readability – one message per section, one unambiguous call to action.

## Execution

Sections, content, visual hierarchy, QA and updates after launch.

## Outcome

Landing page launched with an optimised structure and user flow. How I structure a page like this: [One message per section](../blog/landing-page-user-journey.html).

## What I took from it

A clear structure and unambiguous CTAs do more for the user journey than any single design element.
